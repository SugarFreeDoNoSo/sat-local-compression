# Research workspace instructions

- Write repository content, code, issues, and manuscript prose in English.
- Distinguish query length n and full table length N = 2^n.
- State the computation model, uniformity, access costs, and quantifiers.
- Give mathematical statements stable claim IDs and LaTeX labels.
- Record statuses and dependencies in research/claims.json.
- Include complete proofs or precise citations, retaining every hypothesis.
- Do not claim novelty for standard results or call finite tests proofs.
- Do not replace infinitely many lengths with eventually all lengths.
- Distinguish description length, working memory, gate count, and query time.
- Keep KT, Kt, and K^t distinct.
- Keep proof dependencies acyclic; record counterexamples and failed approaches.
- Run make verify for changes affecting the manuscript or experiments.
- Inspect the rendered PDF after substantial layout changes.
- Claim independent review, formal verification, or successful remote CI only
  when supported by evidence.
- Keep AI-assistance disclosure factual. Human authors control submission,
  authorship changes, and publication licensing.
