# Manuscript

Run make pdf from the repository root. The output is build/paper/main.pdf,
excluded from source control.

The paper uses a neutral article class, numbered theorem environments,
stable labels, BibTeX references, and explicit proof environments.
A publisher-specific class can be introduced after selecting a venue.

Update research/claims.json when statements change. Regenerate data with
make experiments; do not hand-edit data/obdd_widths.tex.
The title-page date identifies the draft, not a scholarly publication.
