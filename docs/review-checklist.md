# Mathematical review checklist

- [ ] The statement is independent of the proof sketch.
- [ ] Variables, encodings, models, and access costs are defined.
- [ ] Universal evaluators have the required simulation efficiency.
- [ ] Description length, work space, and gate count are distinguished.
- [ ] Query length n and full-table length N = 2^n are distinguished.
- [ ] One description works for all queries of a fixed length.
- [ ] Uniform and nonuniform assertions are distinguished.
- [ ] Worst-case, average-case, and probabilistic claims are distinguished.
- [ ] Constants, overhead, and finite exceptions are accounted for.
- [ ] Infinitely-often and eventual quantifiers are correct.
- [ ] Reductions have the correct direction and parameter transformations.
- [ ] Literature results retain all hypotheses and promises.
- [ ] KT, Kt, and K^t are not silently identified.
- [ ] Every proof step follows from a premise or a precise reference.
- [ ] Counterexamples outside the model's restrictions are recorded.
- [ ] Finite experiments are not treated as asymptotic proofs.
- [ ] Established results and original contributions are distinguished.
- [ ] Claim dependencies and citations are current.
- [ ] The PDF has no unresolved references or layout defects.

Record reviewer identity and date only after an actual review.
