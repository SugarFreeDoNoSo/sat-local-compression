# Publication plan

The current working draft establishes the research framework. It is expository
and is not presented as a new complexity separation.

The [independent-review request](docs/independent-review-packet.md) supplies a
source-pinned reading packet and findings-return guide. It selects no reviewer,
venue, license, or contribution, and does not satisfy the review gates below.

The [W06 preparation dossier](docs/w06-publication-preparation.md) records the
contribution inventory, checked bibliographic metadata, technical evidence and
remaining author decisions. Its preparation does not complete the checklist.

Before an external preprint or journal submission:

- [ ] Identify the contribution and complete a novelty/literature review.
- [ ] Obtain independent human review of central claims and assumptions.
- [ ] Resolve blocking proof gaps and retain explicit open targets.
- [ ] Audit encodings, reductions, circuit conventions, and asymptotic scales.
- [ ] Confirm authors, contributions, affiliations, and acknowledgments.
- [ ] Select manuscript and code licenses with the author.
- [ ] Select a venue and follow its actual formatting/disclosure policies.
- [ ] Verify reference metadata against primary sources.
- [ ] Run make verify from a clean checkout and inspect the final PDF.
- [ ] Tag an immutable version and archive matching sources and artifacts.
- [ ] Add a DOI or preprint identifier only after one is assigned.

## Versions

- v0.1.x: foundations, corrections, and reproducibility improvements.
- v0.2.x: reviewed extensions with scoped statements.
- v1.0.0: an author-approved submission snapshot, if the project reaches that stage.

Versions describe repository maturity, not mathematical novelty.
CITATION.cff identifies the living artifact. A later publication can be added
as its preferred citation when the metadata is final.
